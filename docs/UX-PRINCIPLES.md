# Keep Planvisiq easy

The product is for busy planners who want to spend less time assembling reports. Its main journey is **Upload files → Check results → Download report**.

- Keep My project, Files, Reports and Slides as the main navigation. Put specialist tools behind optional controls.
- Offer useful defaults and a short list of common outcomes. The complete catalogue should be searchable without being the first thing a new user sees.
- Match recognised columns and remember confirmed choices for recurring uploads. Show the selected file type and allow corrections; do not silently guess unfamiliar layouts.
- Ask for information only when the current task needs it. Do not require users to build a data model, write formulas or design a dashboard before seeing useful results.
- Explain an issue in ordinary words, show the affected record and offer a direct way to correct it.
- Preserve missing information as missing. Easier reporting must not hide gaps or manufacture confidence.
- Start presentations with a ready-made project deck. Keep content editing separate from layout decisions, preserve saved snapshots and make updates as new copies.
- Fill report layouts, figures and branding automatically. Keep audience, date filters and detailed layout options optional.
- Keep source records and previous versions available without forcing the user through them every time.
- Design optional approvals and team controls around existing workflows when the backend is added. Do not make every download a long administrative process.
- Test the journey with first-time planners and anonymised real files. Measure whether they can complete it without coaching; do not promise zero learning before observing this.

This frontend keeps account, invitation and billing screens clearly identified as previews. The simplicity goal does not change the requirement for secure server-side implementation before accepting customer data.
