01 · Welcome To Planvisiq

Welcome to Planvisiq. Turn project data into clear results. In this quick tour, you will go from a project file to a report, or a presentation ready to share.

02 · Organisation & Sign In

Create an organisation, or find your company on the sign in page. Organisation is where you manage people, roles, user IDs and licence estimates. Accounts and payments are still previews, so use sample details.

03 · My Project

In the workspace, select New project. Enter the project and client, then choose a reporting date. Use the project selector to move between jobs. My project brings the selected job's results together.

04 · Files

Open Files and upload Excel or CSV. Confirm the file type and column matches for each worksheet, then import. You can also attach supporting documents. These stay with the project, but their contents are not automatically read.

05 · Check The Results

Check the results after importing. Review missing values, conflicting dates and progress figures. Open a flagged record to correct it. Saving creates a new version, so earlier data stays available.

06 · My Project & Activities

Return to My project for progress charts and completed work. Change chart options, groupings or scope to focus the view. Under More tools, Activities lets you inspect and update the individual jobs behind the figures.

07 · Reports

In Reports, choose a progress update, weekly report or close out pack. Check the figures, customise the options and add your commentary. Save a draft or revision to keep a record of what you prepared.

08 · Slides

Open Slides and create a project deck. Edit text, charts and tables, add or reorder slides, and choose a theme. Add speaker notes, present from the app, or export an editable PowerPoint for your meeting.

09 · Project Assistant

Open Assistant beside your work to explore progress and exceptions. Check its source links before using a suggestion. The current assistant uses local calculations and guided responses. Live AI is planned for the backend release.

10 · Exports & Settings

Export PDF for a finished report, PowerPoint for slides, or Excel and CSV for the figures. Settings holds branding and workspace backups. This version saves in your browser, so export a backup regularly. You're ready: upload, check, report and share.

Which file should I export?+

PDF — a finished, shareable or printable report.

PowerPoint (.pptx) — editable slides for a stakeholder meeting.

Excel (.xlsx) — structured figures for further analysis.

CSV (.csv) — plain data for another tool or spreadsheet.

Workspace backup (.zip) — a portable copy of project data, reports, decks and attachments. Keep this separately from the files you send to stakeholders.

What about the advanced catalogue?+

Start with the main upload and report choices. The advanced catalogue in Files and Reports offers specialist dataset and report templates. Entries labelled “Template preview” need additional implementation before they produce a complete specialist analysis.

Before using this version

Your work is saved in this browser. Use Settings → Export workspace backup to keep a copy. Company sign-in, permissions, invitations and billing are previews; cloud sharing and live AI will follow with the backend.
